07 / METHODOLOGY
Network classification
Features are classified using the GeoJSON power attribute. Line types include line, minor_line and cable. Substations and power plants are identified by their power classification.

Voltage classification
The dashboard interprets OSM voltage values in volts. The default transmission threshold is 66,000 V (66 kV). Features with no voltage attribute are reported separately.

Length calculation
Line lengths are calculated from consecutive geographic coordinates using the Haversine formula. Values are approximate geodesic lengths and are not engineering-grade network measurements.

Limitations
OSM coverage is not necessarily complete. Missing lines, substations, voltage values or facilities must not be interpreted as evidence that they do not exist.
